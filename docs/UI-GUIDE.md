# 界面控件使用条例

本页约定「汉末会战沙盘」界面的写法：新增或修改界面时**只用这里列出的令牌与控件**，不另起新风格。
控件的实际样子见构建产物 `dist/ui-kit.html`（源文件 `src/ui/kit.html`，与正式页面共用同一份 `styles.css`）。

风格基调：**兵棋桌面**。纸色底、墨色细线、直角、无圆角卡片、无渐变按钮；颜色只用来表达阵营与状态，不做装饰。

---

## 1. 设计令牌（`styles.css` 的 `:root`）

| 令牌 | 用途 | 规则 |
|---|---|---|
| `--panel-2` | 页面底色、表头、选中行底 | 页面 `body` 背景 |
| `--panel` | 卡片、输入框、按钮底色 | 所有容器默认用它 |
| `--map` | 沙盘、地图纸 | 只用于地图类区域 |
| `--ink` / `--ink-2` | 正文 / 次要文字 | 次要文字一律 `--ink-2`，不要用透明度 |
| `--rule` | 细线、边框 | 卡片、输入框、分隔线都用 1px `--rule` |
| `--brass` | **交互强调**：选中、焦点、已修改 | 每屏不宜过多；焦点环固定 2px `--brass` |
| `--a` / `--b`（及 `-soft`） | 甲军（朱红）/ 乙军（靛青） | **只**表示阵营；战役地图里用 `--ca` / `--cb` |
| `--warn` `--bad` `--good` | 动摇 / 不利、错误 / 有利 | 只表示状态 |
| `--f-display` | 标题、大字结论（马善政） | 页面标题、横幅、报告标题，**不用于正文** |
| `--f-glyph` | 兵种字、算子 | 只用于棋子与兵种 |
| `--f-body` | 正文 | 默认 |
| `--f-mono` | 数字、日期、参数值 | 一切需要对齐的数字加 `.mono` |

深色模式：令牌已在 `prefers-color-scheme: dark` 与 `[data-theme="dark"]` 下重定义；**不要写死颜色**（`#fff` 只允许出现在阵营色块上的文字）。

字号阶梯：`11px`（`.lbl`、标签）· `11.5px`（`.note`）· `12–12.5px`（表格、列表）· `14px`（正文）· `18–24px`（大数字、`--f-display` 标题）。

间距阶梯：`4 / 6 / 8 / 10 / 12px`。栏与栏之间 `10–12px`，卡片内 `7–8px`，行内控件 `6px`。

## 2. 版式

### 2.1 页头 `header.top`
```
[标题 h1]  [nav.modes 游玩|编辑器]  [nav.tabs 当前模式的子页]  … [.ver 版本]
```
- `nav.modes`：一级「模式」切换，选中为铜色（同 `.seg`）。
- `nav.tabs`：二级「页面」切换，选中为墨色反白。每个按钮带 `data-view`（目标视图）与 `data-mode`（所属模式）。
- 切页一律走 `showView(id)`，不要直接改 `.view.on`。

### 2.2 视图 `.view`
- 每个页面是 `<div class="view" id="v-xxx">`，同一时刻只有一个 `.on`。
- 战场视图（`v-board`）使用三栏 `.layout`：左「军令」、中「沙盘」、右「战况」；其他视图单栏。
- 「大厅 + 详情」型页面（开局、选战例）用 `.lobby`：左侧宽列表，右侧 340px 详情卡。

### 2.3 卡片 `.card`
```html
<section class="card">
  <h2>标题 <span class="lbl">副标 / 英文</span></h2>
  <div class="body"> … </div>
</section>
```
- 标题栏 `h2` 左标题、右辅助信息或小按钮，二者用 `justify-content:space-between` 自动分开。
- 阵营卡片：`.card.side-card.a` / `.b`，左边 6px 阵营色条，标题带 `.chip`。
- 卡片之间不嵌套卡片；卡片内的分组用 `.lbl` 小标题 + 点线分隔（`border-top:1px dotted var(--rule)`）。
- 可折叠的大分组用 `<details class="ed-sec">`（编辑器专用）。

## 3. 控件

| 控件 | 写法 | 何时用 |
|---|---|---|
| 主按钮 | `<button class="btn primary">` | 每个区域**最多一个**：本区最主要的下一步（出阵、推进一日、开始） |
| 普通按钮 | `<button class="btn">` | 其他操作 |
| 小按钮 | `<button class="btn sm">` | 表格行内、卡片标题栏内 |
| 文字链接 | `<button class="linkbtn">` | 跳转到别的页面（如「在编辑器中调整 →」） |
| 分段选择 | `<div class="seg"><button aria-pressed="true">…` | 2–6 个互斥选项且都要一眼看到（地形、模式、阵营） |
| 下拉 | `select.full` / `.form-row select` | 选项多于 6 个 |
| 滑杆 | `.slider-row`：`标签 · range · output` | 连续数值；`output` 用等宽字；阵营色由外层 `--side` 决定 |
| 计数器 | `.step`：`− input +` | 整数部数 |
| 勾选 | `<label class="chk"><input type="checkbox"> 文字</label>` | 开关 |
| 小标签 | `.lbl` | 字段名、分组名（小号字距加宽） |
| 说明 | `.note` | 一切解释性文字 |
| 键值表 | `<dl class="kv">` / `<dl class="brief-row">` | 只读属性列表 |
| 进度条 | `.meter > i`（阵营色）/ `.mbar > i`（铜色） | 兵力、粮草、进度 |
| 标签组 | `.flags > span(.good/.bad)`、`.pen > span(.ok)` | 状态、标签 |
| 徽记 | `.histbadge`、`.stage-pill`、`.day-pill`、`.phase-pill` | 模式、日期、阶段 |
| 列表项 | `<button class="pick">`（`.on` 选中、`.gone` 失效） | 可点选的条目：剧本、战例、军团 |
| 可编辑表 | `table.edit` 包在 `.tbl-wrap` 里 | 参数表 |
| 日志 | `.log > table` | 战报、日志，最新在上 |
| 快捷键 | `<kbd>` 放在 `.kbd-hint` 里 | 操作提示 |

### 原生控件已统一主题（直接写原生标签即可）
- `<select>`：已去掉系统外观，直角细框、墨色折角箭头，悬停变 `--panel-2`。**不要**再用 `background` 简写去覆盖它（箭头已用 `!important` 保护）；只需按场景设宽度和内边距。
- `<input type="range">`：细轨 + 算子式方形滑块；已拖过的一段着 `--side`（在阵营卡里自动是阵营色，其他地方是铜色）。比例由 `main.js` 的 `fillRange` 写入 `--fill`，新加的滑杆不用另外处理。
- `<input type="checkbox">`：直角小方框，选中填铜色；放在 `.chk` 或 `.cp-chk` 里配文字。
- `<input type="number">`：不显示上下箭头，靠键盘输入；文本框、多行文本统一直角。
- 滚动条：细、`--rule` 色，自动生效。
- 不要再写 `accent-color`、圆角或系统默认外观。

### 状态写法
- 选中：`aria-pressed="true"`（按钮组）或 `aria-selected="true"`（页签）或 `.on`（列表项）。**不要**用自定义颜色类表示选中。
- 已修改的参数：输入框加 `.changed` / `.chg`（铜色边）。
- 禁用：`disabled` 属性，样式自动变淡。
- 错误：`.ed-err` 方框；单个数值偏坏用 `.cbad`，偏好用 `.cgood`。

## 4. 写界面的规则

1. **先找现成控件**：本表没有的，先在 `src/ui/kit.html` 里加上并写进本文件，再在页面中使用。
2. **不写内联颜色**；内联 `style` 只用于一次性的尺寸/间距微调。
3. **一屏一个主按钮**；危险操作（删除、恢复默认）用普通按钮并在文字里说清后果。
4. 阵营一律「甲 = `.a` = 朱红、乙 = `.b` = 靛青」；战役中由攻方坐甲位，必要时 `body.flip` 互换颜色。
5. 数字用 `.mono`，比例写成 `%`，兵力写成「万」或「部」。
6. 文字用中文书面语，简短；按钮用动词开头（「出阵」「推进一日」「返回大厅」）。
7. 每个可点击元素都要能用键盘操作：用 `<button>`，或给 SVG 元素加 `tabindex="0" role="button"`。
8. 窄屏（< 760px）一律回落为单栏，不出现横向滚动（沙盘和宽表格除外，它们在自己的容器内滚动）。

## 6. 地图

- 战役道路一律画成曲线：用 `camp_ui.js` 的 `roadD` / `roadSeg` / `roadAt`，同一条路的弯法由两端据点 id 决定，所以地图、行军路线、军团位置和编辑器预览完全重合。**不要**再用 `<line>` 或 `<polyline>` 画道路。
- 道路分两层：`.cp-road-bed`（宽、淡的路基）在下，`.cp-road`（细墨线）在上。
- **两种箭头**：大箭头 `.cp-march` 是示意——在**下达目标时**按 `army.order.seq` 画出，此后不随时段变化，抵达或改令即撤；小尖头 `.cp-step`（`stepArrow`）是当下一步，逐时段更新。
- **大箭头** `.cp-march`：用 `marchArrow(路线, 据点)` 生成——尖尾、渐粗、倒钩箭头，整条至多一个弯（不逐段贴道路）；撤退加 `.retreat`，画成空心虚线箭头，半透明阵营色加深色描边；统一放在 SVG **最上层** `<g class="cp-arrows">`，`pointer-events:none` 不挡点击；选中军团的箭头 `.on` 加深。
- **兵旗卡片** `.cp-army`（88×30）：左为阵营色燕尾旗，写主将姓（`--f-glyph`）；右为纸色卡，写主将名、部数，下方两条细条分别是兵员（阵营色）与组织（`--good`，军心动摇时 `--warn` 且卡框变虚线）。任务标签 `.ca-tag` 放在卡片外侧（甲在左、乙在右），不与上下叠放的卡片相压。选中为铜色描边加光晕。
- 地图都用 `<svg class="cmap" viewBox="0 0 1000 800">`，绘制函数集中在 `src/ui/map_svg.js`：`mapBaseSVG`（底图）、`flagsSVG`（兵旗）、`marksSVG`（⚔ 会战、火 焚粮/火攻、克 攻占、溃 溃散）、`arrowPath` / `marchArrow`（进军箭头）、`mapFrameSVG`（报告用的做旧图框）。新地图不要另写一套。
- 报告地图（`.rmap`）多一层纸面暗角与双线图框，左上标题框（`--f-display`）、左下图例框、右上指北针；**实心箭头**为已发生的进军，**虚线箭头**（`.cp-plan`）为既定去向。
- 战役左栏的时段条 `.ph-bar`：六格，当前（下一）时段铜色，已过的变淡，夜间两格用 `--panel-2` 底。暂停原因用 `.cp-pause` 方框列出。

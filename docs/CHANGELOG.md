# 版本记录

## 0.25.0 战役批量推演
- 编辑器「批量推演」分为「战斗批量 / 战役批量」两种。
- 战役批量：选剧本、局数（20–200）、起始种子、自由推演或历史模式（含倾向），可临时覆盖两军主帅的统帅、智略。
  - 结果：胜率与罢兵比例、平均历时与会战数、结局分布、结束日数分布、逐条史实结局的应验率；双方平均兵员损失、被焚存粮、火攻得手、断粮、军心大震与各类 AI 决策次数。
  - 逐局明细：种子、结局、日数、会战数、吻合度；「重演」即在战役编辑的沙盘中按同一种子推一遍（结局相同）。
  - 可中途停止；设置记在本浏览器（`hm-cbatch-v1`）。

## 0.24.0 回顾战果、界面文字不可选
- 战役报告：示意图、每日战况上的 ⚔ 会战图标，以及「会战一览」的每一行，点开即弹出战果卡——时段跨度、攻守双方与将领、战前战后兵员、各兵种损失、胜负与缘由、回合与时段、焚辎重、追击损失。同一地点多战则一并列出；Esc 或点外面关闭。
- 战报记录新增：战前战后兵员、各兵种损失、回合、实占时段、撤出方、追击损失（旧存档只显示一行战报）。
- 界面文字：按钮、页签、标签、列表项、时段条、地图、战场、兵牌、图例、卡片标题不可选中；战报、日志、说明、史书体与输入框仍可选。

## 0.23.0 新剧本：赤壁、合肥、汉中
- **赤壁之战（建安十三年冬）**：孙刘联军对曹军。乌林曹营与水寨相连（林木连营），东南风起，黄盖火船夜焚水寨，周瑜、刘备水陆并进，曹操自华容道败归江陵。历史模式锚点 15 条。
- **合肥之战（建安二十年秋）**：张辽七千守合肥对孙权。张辽拂晓陷阵、冲垒焚营（吴人夺气）；疾疫；诸军先发，孙权殿后，逍遥津遇袭。历史模式锚点 12 条。
- **汉中之战（建安二十四年春）**：刘备对夏侯渊、张郃，曹操自斜谷来援。黄忠夜烧走马谷鹿角，斩夏侯渊；曹公「鸡肋」引还，刘备遂有汉中。历史模式锚点 14 条。
- 史实结局新增判定 `battle`（某地会战某方胜或奇袭得手）。
- 规则：过午晚到、隔营相望的两军，次日清晨须先接战，不得趁晓先走（败者战后再退）——追击得以成立。
- 剧本导出 scenarios/chibi.json、hefei.json、hanzhong.json。

## 0.22.0 编辑器调试台
- 战斗编辑改为三栏调试台：左为编成（战场、甲军、乙军），中为实时战场（改动即重新布阵），右为调试面板与战况。
  - 调试面板：固定 / 更换随机种子、同种子重来；快进到下一时段、下一日、结束；点选兵牌直接改兵员、组织度、体力；快速批量（种子 1–N）看胜负、回合、时段、损失与结束原因。
- 战役编辑改为三栏调试台：左为剧本编辑，中为「沙盘试推」（按当前剧本重建一局 AI 对 AI，改剧本即自动重建），右为沙盘调试。
  - 沙盘调试：种子、历史模式；推进一时段 / 一日 / 到下次交战 / 到结束；点兵旗改军团兵员、组织、粮、军心、军令，点据点改归属、存粮、营垒、城墙；快速批量看结局分布、平均日数与史实吻合度。
  - 沙盘不存档，与玩家的战役进度互不相干。
- 战役地图的军团图层（大箭头、小尖头、兵旗）抽为 `armyLayers`，玩家地图与沙盘共用。

## 0.21.0 战斗层六时段
- 战斗引擎带时钟：自开战时段逐段推进（白天每段 4 回合、傍晚 3、夜间 5），跨时段、跨日连续进行。
- 傍晚议事；新方略「夜战续攻」：不解甲转入夜战，至晓略作休整。夜间时段自动按夜战论。
- 战役交战按开战时段开打，白天打到傍晚、夜袭打到清晨；实占时段精确交回战役（取代按回合估算），跨日之战次日不再另开一战；战报写明「清晨至傍晚」「前半夜至次日清晨」。
- 界面：战场顶部时段条与「第 N 日 · 时段」；战报行首标时段；战斗编辑可选开战时段，「奇袭」改为拂晓奇袭；选战例大厅显示开战时段。
- 规则编辑：`DAY_ROUNDS` 改为 `PH_ROUNDS_DAY` / `PH_ROUNDS_DUSK` / `PH_ROUNDS_NIGHT`；战役参数去掉 `NIGHT_ROUNDS`。
- 新增战斗时钟测试 3 项（共 23 项）。

## 0.20.0 六时段、自动推进与事件暂停
- 引擎：一日六时段（后半夜、清晨、上午、下午、傍晚、前半夜）。行军按时段，奇兵夜行且不在路上与敌相遇；一地一日至多一战，过午抵达者次日清晨再战；战斗回合按开战时段折算；交战占去时段。粮草、恢复、天气、胜负仍按日结算。
- 战略 AI：每日议定一次，遇敌情或粮仓被袭当日临时重议一次。
- 界面：时段条；「一时段 / 推进一日 / 自动」三种推进；自动推进遇设定的要事暂停（接敌、粮仓被袭、军团抵达、敌军进入视野、军心动摇、史实之机，可勾选）。
- 地图箭头：大箭头只在下达目标时画出并定格，小尖头逐时段显示当下一步。
- 报告：每日战况可逐时段回放（«» 跳日、◀▶ 跳时段，夜间压暗），日志按时段筛选。
- 存档键升为 `hm-camp-v3`；未处理的交战随存档保存。编辑器「战役参数」新增 `LATE_ENGAGE_PH`、`NIGHT_ROUNDS`、`NEAR_DAYS`。
- 新增 tests/periods.test.js（7 项）。

- 战场左栏新增「军令」：开战前选阵型与主将位置、只能调动己方兵牌；开战后亲自下达战术，或交由副将（战术 AI）自择。战役中亲自指挥的会战同样适用。

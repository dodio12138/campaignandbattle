# 版本记录

## 0.19.1 箭头重绘
- 进军箭头不再逐段贴着道路弯：取起点、终点和路线上最偏的一个据点拟成一条曲线，整条至多一个弯。
- 箭形改为尖尾、渐粗、倒钩箭头，加轻微投影。
- 进军与撤退区分：进军为实心箭头，撤退（奉撤回之令）为空心虚线箭头；战役地图、示意图、每日战况及图例一致。

## 0.19.0 战役示意图与每日战况
- 战役报告新增「战役示意图」：全程进军箭头（粗细示兵力，标主将与起止日）、会战 / 焚粮 / 攻占 / 溃散标记、终局兵旗、标题框、图例、指北，纸面做旧图框。
- 新增「每日战况」：逐日回放（拖动、前后一日、播放与调速），显示当日归属、存粮、兵旗、当日行进（实心箭头）与既定去向（虚线），下附当日日志。
- 两张图都可「下载 PNG」（2000×1600）。
- 引擎快照新增逐日军团位置与据点归属（`stats[].armies`、`stats[].owners`）；旧存档无此记录，会提示新开一局。
- 地图绘制抽出为 src/ui/map_svg.js，战役地图与报告共用。

## 0.18.3 兵旗卡片与进军箭头
- 战役地图军团改为兵旗卡片：阵营色燕尾旗写主将姓，卡上有主将、部数、兵员条与组织条；军心动摇时卡框变虚线；任务标签移到卡片外侧。
- 行军路线改为经典作战地图的进军箭头（燕尾、渐宽、宽箭头），画在地图最上层，不挡点击。

## 0.18.2 修正
- 修正：战役地图「← 开局」无法返回开局页；编辑器「开始战役 / AI 观战试推」后停在开局页；战场上「只能调动己方兵牌」与「（你）」标记未生效（PLAY 未挂到 window）。
- 战役结束后，开局页仍可「查看战果」回到地图与报告。
- 新增 `npm run serve`：本地预览且不缓存。

## 0.18.1 控件主题与曲线道路
- 下拉框、滑杆、勾选框、数字输入框、滚动条统一为兵棋桌面风格（直角、墨线、铜色强调、阵营色滑杆），深浅两色主题都适配。
- 战役地图的道路改为曲线（弧形或 S 形，按据点固定），行军路线、军团行进位置、编辑器预览随之弯曲；道路加淡色路基。

## 0.18.0 游玩 / 编辑器 两种模式
- 页头分两级：「游玩」（战役、战斗）与「编辑器」（战役编辑、战斗编辑、战术、规则、批量推演）。
- 战役开局大厅：选剧本、选扮演的一方或观战、历史模式与随机种子；可继续上次进度。
- 选战例大厅：按会战模式筛选，看双方编成与目标，选甲军、乙军或观战后出阵。
- 战场左栏新增「军令」：开战前选阵型与主将位置、只能调动己方兵牌；开战后亲自下达战术，或交由副将（战术 AI）自择。战役中亲自指挥的会战同样适用。
- 战役地图工具栏精简：「同种子重演」「再开一局」移入战役报告；自动推演只在观战时出现；编辑器里新增「AI 观战试推」。
- 战斗编辑可「在战场试演」，试演完返回编辑器。
- 新增界面控件条例 docs/UI-GUIDE.md 与控件样板页 dist/ui-kit.html（源文件 src/ui/kit.html）。

## 0.17.0（v17）项目化
- 由单文件 Artifact 拆分为项目：src/（引擎、剧本、界面）、tools/（构建、加载、批量推演、剧本导出）、tests/、docs/。
- 剧本数据从 campaign.js 分离到 src/data/scenarios.js，并导出 scenarios/*.json。

## v17 战役设置与夷陵之战
- 新标签「战役设置」：基本与主帅、据点（拖动定位）、道路、军团、胜负条件、历史模式、战役参数；新建、复制、删除，以及 JSON 导入导出；实时校验。
- 新剧本：夷陵之战（章武二年）。
- 新规则：火攻营寨（天时 × 林木 × 智略，沿连营蔓延）、天气延续、季节随纪年推移。
- 新 AI 方略：火攻（智者待时）、进逼强攻、留守要地。

## v16.1 烧仓与截粮；AI 一键推演
- 烧粮仓按焚粮占全军存粮之比造成军心大震与多日动摇；截粮只伤粮，过半时小挫。
- 新 AI 方略：乘乱击之、军心动摇时主帅议退。
- 修正：倒戈军不与原友军同点开战；败退军团中途续退原定目的地。
- 战役页「AI 一键推演」（慢 / 中 / 快 / 瞬时，可停止，可新开一局）。

## v16 历史模式
- 随机种子（全局 RNG 种子化，可同种子重演）；史实倾向；8 类史实锚点；史书体纪事与「史臣曰」；史实吻合度；20 局批量检验。

## v15 战略 AI 与战役报告
- 双方主帅按统帅、智略、性格决策：情报误差、迟疑、行动路数、截粮与围魏救赵、预设防备、择天时、退兵。
- 战役报告：双方兵员与粮仓折线图、转折点、会战一览、军团表现、决策年表。

## v14 战役大地图
- 官渡战役地图：粮仓、运粮队、军团任务；遭遇即转入战场，可亲自指挥或速决；任务目标进入战斗 AI（焚粮、坚守、护粮），撤离阈值。
- 天气与夜战状态；辎重兵种。

## v8–v13 战斗层
- 城防与器械（只有器械伤墙，登城后才白刃）、盾网与修补、器械可被摧毁。

- 自定义布阵与一键阵型；白马、官渡两个战例；全部战术与规则可编辑。
